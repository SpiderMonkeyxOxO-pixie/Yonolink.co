Arcade is the most varied category in the Yono directory — apps here don't focus on one game type the way Rummy or Slots apps do, but bundle several game types into a single app.

---

## What makes an app "Arcade" in this directory

We classify an app as Arcade when it combines multiple distinct game types — card games, spin-style games, and other formats — inside one platform, rather than specializing in a single format. This is a directory-depth classification, not a full feature review of any individual app; for a deeper look at a specific Arcade platform, see that app's own dedicated page where one exists, such as [Yono Arcade](/app/yono-arcade).

## Common features across Arcade apps

- Multiple game types within one app, rather than a single specialty
- Leaderboards and daily challenges in several of the platforms
- Fast-paced, shorter session lengths compared to a full Rummy table

Feature sets vary by app — check each app's own page for what it specifically includes before downloading.
