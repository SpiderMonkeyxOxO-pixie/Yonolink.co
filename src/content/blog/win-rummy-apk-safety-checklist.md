## Why You Should Always Check an APK Before Installing

Android apps downloaded outside of the Google Play Store are called "sideloaded" APKs. Unlike Play Store apps, sideloaded APKs are not automatically reviewed by Google. A fake or modified APK can:

- Request permissions it doesn't need (contacts, SMS, call logs)
- Silently collect personal data
- Contain adware or spyware
- Crash or malfunction on your device

This is why running a checklist before installing any APK — especially from a new platform — matters.

## 14-Point Win Rummy APK Safety Checklist

Use this checklist once an official APK is available for download.

### 1. Confirm the Source is Official

Only download from the link published on **winrummy.com** or from a trusted directory that links directly to the official file. Do not use APKs shared via WhatsApp, Telegram groups, or unofficial APK mirror sites.

### 2. Check the Package ID

Every Android app has a unique package identifier (e.g., `com.winrummy.app`). When you install an APK, your device shows the package ID. Compare it to the package ID listed on the official Win Rummy website. A mismatch means the file is not the legitimate app.

*Note: Win Rummy's package ID is not yet public. Check winrummy.com on launch day.*

### 3. Verify the File Size

Legitimate rummy apps are typically 30–60 MB. If a file claiming to be Win Rummy is unusually small (under 5 MB) or very large (over 200 MB), treat it with suspicion.

### 4. Scan With Google Play Protect

Before opening the APK file:
1. Open **Google Play Store**
2. Tap your profile icon → **Play Protect**
3. Tap **Scan** and select the downloaded file

Play Protect will flag known malware signatures. Always run this scan before tapping Install.

### 5. Use a Secondary APK Scanner

In addition to Play Protect, upload the APK to **VirusTotal** (virustotal.com). VirusTotal runs the file through 70+ antivirus engines and reports any detections. A clean scan does not guarantee safety, but multiple detections are a clear warning sign.

### 6. Check the Digital Signature

Every APK is signed by its developer using a certificate. You can verify the certificate using a tool like **APK Signature Verifier** (available on Play Store). The developer name on the certificate should match the company behind Win Rummy. Avoid any APK signed by an unknown or generic certificate.

### 7. Review Requested Permissions

When you install an APK, Android shows the permissions it requests. For a rummy app, normal permissions include:

- Internet access
- Storage (for game assets)
- Camera (optional, for KYC)

**Red flags** — permissions a rummy app should never need:

- Read/send SMS
- Access call logs
- Read contacts
- Record audio (unless explained)
- Device admin rights

If you see these, do not install.

### 8. Enable "Install Unknown Apps" Only Temporarily

To install an APK, you must enable **Install Unknown Apps** for your file manager or browser in Android Settings. Enable it only for the download session, then disable it immediately after installation. Leaving it on permanently increases your device's exposure to malicious files.

### 9. Check the Download URL

The URL you download from should begin with `https://` and be hosted on a domain you can verify as belonging to Win Rummy (e.g., winrummy.com or a CDN they officially announce). Avoid shortened links (bit.ly, tinyurl) for APK downloads.

### 10. Look at the App Store Listing (If Available)

Some rummy apps also publish on third-party app stores. If Win Rummy lists on a store like APKPure or Uptodown, check the publisher name, upload date, and user reviews. Fake listings often have no reviews or copy-paste descriptions.

### 11. Read the Permissions Screen During Install

Even after scanning, read the permissions screen one final time when you tap Install. Android shows a summary of what the app can access. If new permissions appear that weren't shown before, tap Cancel and investigate.

### 12. Monitor Data Usage After Install

After installation, check your phone's **data usage** (Settings → Network → Data Usage → select Win Rummy). A rummy app should only use data when you open it. If it shows background data usage when the app is closed, it may be transmitting data without your knowledge.

### 13. Check for Automatic Updates

Official apps notify you of updates through their own in-app system. Be suspicious of any notification from a third-party source asking you to update a sideloaded app — this is a common method for pushing modified versions.

### 14. Only Play on Registered Accounts

Once installed, only use your own registered account. Never share your phone or account credentials. Win Rummy, like other rummy platforms, requires KYC verification before withdrawal — your account is tied to your identity.
