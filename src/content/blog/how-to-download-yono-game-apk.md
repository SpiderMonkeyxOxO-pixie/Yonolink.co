## Why Are Yono Games Distributed as APKs?

APK stands for Android Package Kit — the file format Android uses to install applications. Most apps you use daily arrive through the Play Store, which handles the APK delivery behind the scenes. Yono apps skip the Play Store and deliver the APK file directly.

This is common across a broad range of real-money gaming apps in India. Direct APK distribution gives app developers more flexibility over updates, bonus structures and availability — without being subject to app store policies that restrict real-money gaming applications.

The result is that installation requires one additional step: enabling your device to accept installs from sources outside the Play Store.

### Step 3 — Enable Install from Unknown Sources

This is the step most users encounter for the first time. Android blocks APK installations from outside the Play Store by default. You need to grant permission once per app or once globally, depending on your Android version.

**Android 8.0 and above (most current devices):**
When you tap the downloaded APK to install it, Android will show a prompt asking if you want to allow installation from that source (usually your browser). Tap **Allow** or **Allow from this source**. This permission applies only to that browser — it does not globally disable Android's security.

**Android 7.0 and below:**
Go to Settings → Security → Unknown Sources and toggle it on. This is a global setting on older Android versions.

If you are unsure which Android version you are running, go to Settings → About Phone → Android Version.
